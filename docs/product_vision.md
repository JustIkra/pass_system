# Product Vision: Система прогнозирования загрузки окон МФЦ

**Версия:** 1.0
**Дата:** 2026-02-09
**Статус:** Draft

---

## 1. Пользователи

| Роль | Описание | Частота использования |
|------|----------|-----------------------|
| **Руководитель МФЦ** | Принимает стратегические решения по распределению ресурсов между 44 филиалами | Еженедельно |
| **Менеджер филиала** | Управляет штатом 5-15 сотрудников и окнами (1-35). Отвечает за операционную эффективность | Ежедневно |
| **Планировщик / HR** | Составляет графики смен и распределяет сотрудников по окнам и ролям | Еженедельно |

---

## 2. Проблема

Сеть МФЦ Курской области: **126 000 операций/месяц**, **44 филиала**, **53 типа окон**, **~400 сотрудников**.

### Ключевые боли

1. **Неравномерная загрузка окон** -- часть перегружена (очередь >30 мин), часть простаивает. ~3% посетителей не дожидаются очереди.
2. **Нехватка/избыток сотрудников** -- графики составляются "по опыту", без количественного прогноза потока.
3. **Реактивное управление** -- проблемы видны только в отчётах за прошлый месяц, нет возможности подготовиться к пикам.
4. **Ручной анализ 1.7 GB данных нереален** -- данные лежат в CSV помесячно.

---

## 3. Решение

Web-приложение, которое на основе исторических данных АИС (2023-2024) строит **прогноз загрузки** каждого филиала и его окон **на месяц вперёд** с разбивкой по дням и часам.

### Ключевые возможности

1. **Прогноз загрузки** -- модель временных рядов предсказывает количество обращений, время ожидания и обслуживания
2. **Интерактивный дашборд** -- визуализация с фильтрами по филиалу, периоду. Heatmap "день x час"
3. **Выявление дисбалансов** -- автоматическое определение перегруженных и простаивающих окон
4. **Рекомендации по штату** -- сколько окон и сотрудников нужно в каждый час

### Чего приложение НЕ делает
- Не заменяет АИС, не управляет очередью в реальном времени
- Не принимает решения автоматически -- только рекомендации

---

## 4. User Stories

### US-1: Прогноз загрузки по филиалу
> **Как** руководитель МФЦ, **я хочу** выбрать филиал и увидеть прогноз на месяц, **чтобы** понять пиковые дни/часы.

### US-2: Перегруженные и простаивающие окна
> **Как** менеджер, **я хочу** видеть загрузку по окнам с цветовой индикацией, **чтобы** перераспределить сотрудников.

### US-3: Рекомендации по штату
> **Как** планировщик, **я хочу** получить рекомендацию: сколько сотрудников нужно по часам, **чтобы** составить оптимальный график.

### US-4: Сравнение филиалов
> **Как** руководитель, **я хочу** сравнить загрузку филиалов, **чтобы** перераспределить ресурсы между ними.

## 5. MVP Scope

### Включено

| # | Фича | Приоритет |
|---|-------|-----------|
| F1 | Загрузка и обработка CSV данных из АИС | Must |
| F2 | ML-модель прогнозирования (Prophet/ARIMA) | Must |
| F3 | Дашборд прогноза по филиалу (графики + heatmap) | Must |
| F4 | Таблица загрузки по окнам (цветовая индикация) | Must |
| F5 | Рекомендации по штату на основе нормативов | Should |
| F6 | Сравнение филиалов | Should |
| F7 | Историческая аналитика (факт vs прогноз) | Should |

### НЕ включено (отложено)
- Live-интеграция с АИС
- Автоматическое составление графиков смен
- Прогнозирование по типу услуги
- Аутентификация и ролевая модель
- Мобильная версия, уведомления

## 6. Метрики успеха

### Качество прогноза
| Метрика | Цель |
|---------|------|
| MAPE (ошибка прогноза обращений) | < 20% на уровне филиал/день |
| MAE по времени ожидания | < 5 минут |
| Точность определения пиков (top-3 часа) | > 70% |

### Продуктовая ценность
| Метрика | Цель |
|---------|------|
| Активные пользователи в неделю | >= 5 |
| Доля менеджеров, использующих прогноз | > 50% через 2 месяца |
