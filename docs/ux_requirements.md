**Дата:** 2026-02-09
**Статус:** Draft
**Связанные документы:** [Product Vision](product_vision.md), [Technical Requirements](technical_requirements.md)

## 1. Принципы UX

### 1.1. Целевая аудитория и контекст использования

Приложение создано для **госслужащих МФЦ** (руководители, менеджеры филиалов, планировщики/HR). Это профессиональный инструмент для ежедневной и еженедельной работы с прогнозами загрузки.

### 1.2. Ключевые принципы

| # | Принцип | Описание |
|---|---------|----------|
| P1 | **Чистый профессиональный интерфейс** | Минимум визуального шума, нет декоративных элементов, нет анимаций ради анимаций. Интерфейс должен восприниматься как серьезный рабочий инструмент, а не развлекательный продукт. |
| P2 | **Данные на первом месте** | Каждый пиксель экрана должен нести полезную информацию. Минимум декораций, максимум данных. Числа, таблицы и графики -- основа визуального языка. |
| P3 | **Быстрый доступ к ключевым метрикам** | Любой прогноз должен быть доступен за **не более 2 кликов** от главной страницы. Ключевые KPI видны без скролла. |
| P4 | **Единообразие цветовой кодировки** | Цвета загрузки одинаковы на всех страницах и во всех компонентах: таблицы, heatmap, индикаторы. |
| P5 | **Предсказуемость** | Навигация и поведение интерфейса одинаковы на всех страницах. Пользователь не должен «искать» функции. |

### 1.3. Типографика и визуальный стиль

- **Шрифт:** системный стек (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`) -- максимальная скорость загрузки, привычный вид в рабочей среде.
- **Фон:** светло-серый `#F9FAFB` для основного контента, белый `#FFFFFF` для карточек и таблиц.
- **Текст:** основной `#111827`, второстепенный `#6B7280`.
- **Акцентный цвет:** `#2563EB` (синий) -- для активных элементов навигации, ссылок, кнопок.
- **Разделители:** `#E5E7EB`, толщина 1px.
- **Скругления:** `border-radius: 8px` для карточек и контейнеров, `4px` для кнопок и инпутов.
- **Тени:** минимальные (`shadow-sm`) только для карточек и модальных окон.

## 2. Навигация

### 2.1. Общая структура

```
+------------------+----------------------------------------------+
| Sidebar          | Top Bar                                      |
| (список          | [МФЦ Прогноз]        [Месяц: 2026-03 v]     |
|  филиалов)       +----------------------------------------------+
|                  |                                              |
| [Поиск...]       | Content Area                                |
|                  |                                              |
| * Все филиалы    | (Страница: Overview / BranchDetail /         |
| * Филиал 1       |  Windows / Staffing / Compare / History)     |
| * Филиал 2       |                                              |
| * ...            |                                              |
|                  |                                              |
| [Сравнение]      |                                              |
+------------------+----------------------------------------------+
```

### 2.2. Sidebar (Левая панель)

- **Ширина:** 280px (фиксированная), возможность сворачивания до 64px (только иконки).
- **Содержание:**
  - Логотип / название системы вверху.
  - Поле поиска филиала (фильтрация по названию, client-side, без задержки).
  - Список филиалов (скроллируемый). Каждый элемент: название + мини-индикатор загрузки (цветная точка).
  - Клик по филиалу -- переход на `/branch/:id`.
  - Активный филиал выделен фоном.
  - Внизу: ссылка «Сравнение филиалов» -> `/compare`.
- **Сортировка списка:** по умолчанию -- по алфавиту. Опция -- по уровню загрузки (самые загруженные сверху).

### 2.3. Top Bar (Верхняя панель)

- **Высота:** 56px (фиксированная).
- **Содержание:**
  - Слева: название системы «МФЦ Прогноз» (клик -> главная `/`).
  - Справа: **MonthPicker** -- выпадающий список для выбора месяца прогноза. Формат отображения: «Март 2026». Доступные месяцы: текущий + 2 следующих.
- **MonthPicker является глобальным:** выбранный месяц применяется ко всем страницам. Смена месяца не сбрасывает выбранный филиал.

### 2.4. Табы на странице филиала

При переходе на страницу филиала `/branch/:id` отображаются табы:

| Таб | URL | Описание |
|-----|-----|----------|
| **Прогноз** | `/branch/:id` | Line chart + heatmap (по умолчанию) |
| **Окна** | `/branch/:id/windows` | Таблица загрузки по окнам |
| **Штат** | `/branch/:id/staffing` | Рекомендации по количеству сотрудников |
| **История** | `/history/:id` | Исторические данные (факт vs прогноз) |

- Активный таб выделен подчеркиванием и цветом (`#2563EB`).
- Переключение табов не перезагружает header и KPI филиала.

### 2.5. Breadcrumbs

Формат: `Главная > Название филиала > [Табы: Окна / Штат / История]`

- Каждый элемент кликабелен.
- Разделитель: `>` (символ или шеврон-иконка).

## 3. Цветовая система загрузки

### 3.1. Шкала загрузки

Единая цветовая шкала используется **на всех страницах и во всех компонентах** (таблицы, heatmap, индикаторы, бейджи):

| Уровень | Диапазон | Цвет | HEX | Текст на фоне | CSS-класс |
|---------|----------|------|-----|----------------|-----------|
| **Критическая перегрузка** | > 85% | Красный | `#EF4444` | Белый | `load-critical` |
| **Высокая загрузка** | 70--85% | Оранжевый | `#F97316` | Белый | `load-high` |
| **Нормальная загрузка** | 50--70% | Зеленый | `#22C55E` | Белый | `load-normal` |
| **Низкая загрузка** | 20--50% | Голубой | `#3B82F6` | Белый | `load-low` |
| **Простой** | < 20% | Серый | `#9CA3AF` | Белый | `load-idle` |

Примечание: загрузка может быть > 100% (спрос выше типовой емкости), в этом случае считается **критической перегрузкой**.

### 3.2. Правила применения

- **Таблицы:** цветная точка/бейдж в столбце «Статус» + подкрашенная ячейка.
- **Heatmap:** цвет ячейки по шкале (градиентный переход между уровнями).
- **KPI-карточки:** цвет числа или подложки при выходе за нормальные границы.
- **Sidebar:** мини-точка рядом с названием филиала (цвет = средняя загрузка).

### 3.3. Градиент для Heatmap

Для heatmap используется непрерывный градиент на основе значений:
- Минимум (0 обращений): `#F3F4F6` (светло-серый).
- Максимум (пиковое значение): `#EF4444` (красный).
- Промежуточные значения: линейная интерполяция через `#22C55E` (зеленый) -> `#F97316` (оранжевый) -> `#EF4444` (красный).

## 4. Требования к каждой странице

### 4.1. Overview (Главная) -- `/`

**Назначение:** Общая картина загрузки сети МФЦ на выбранный месяц. Точка входа для руководителя.

**Структура:**

```
+------------------------------------------------------------+
| KPI-карточки (4 шт., одна строка):                         |
| [Всего обращений]  [Ср. ожидание]  [Перегруженных] [Простой]|
+------------------------------------------------------------+
| Top-5 перегруженных        | Top-5 недогруженных           |
| (мини-таблица)             | (мини-таблица)                |
+------------------------------------------------------------+
| Таблица всех филиалов (с поиском, сортировкой)             |
+------------------------------------------------------------+
```

**KPI-карточки:**

| # | Карточка | Значение | Источник |
|---|----------|----------|----------|
| 1 | Всего обращений (прогноз) | Число, формат: `126 000` | `overview.total_predicted_visits` |
| 2 | Среднее время ожидания | Минуты, формат: `11,5 мин` | `overview.avg_predicted_wait` |
| 3 | Перегруженных филиалов | Число + иконка предупреждения | Кол-во филиалов с `avg_wait > 20 мин` |
| 4 | Простаивающих филиалов | Число | Кол-во филиалов с `avg_load < 30%` |

- Карточки расположены в одну строку на ширине >= 1280px.
- Каждая карточка: белый фон, легкая тень, скругление 8px.
- Высота: 96px. Внутри: крупное число (24px bold), подпись (14px, серый), опциональный тренд (стрелка вверх/вниз + процент к предыдущему месяцу).

**Top-5 таблицы:**

- Две таблицы рядом: «Самые загруженные» и «Самые недогруженные».
- Столбцы: Название филиала, Прогноз обращений, Ср. ожидание, Статус (цветной бейдж).
- Клик по строке -> переход на `/branch/:id`.

**Таблица всех филиалов:**

| Столбец | Формат | Сортировка |
|---------|--------|------------|
| Название | Текст | По алфавиту |
| Прогноз обращений/мес | Число с разделителями | По убыванию/возрастанию |
| Ср. ожидание (мин) | `XX,X` | По убыванию/возрастанию |
| Кол-во окон | Число | По убыванию/возрастанию |
| Статус загрузки | Цветной бейдж | По уровню загрузки |

- **Сортировка по умолчанию:** самые нагруженные сверху (по ср. ожиданию, по убыванию).
- **Поиск:** текстовое поле над таблицей, фильтрация по названию (client-side, без задержки).
- **Клик по строке:** переход на `/branch/:id`.
- **Пустое состояние:** «Нет данных прогноза на выбранный месяц. Запустите генерацию прогноза.»

### 4.2. Branch Detail (Филиал) -- `/branch/:id`

**Назначение:** Детальный прогноз загрузки конкретного филиала. Основной экран для менеджера филиала.

**Структура:**

```
+------------------------------------------------------------+
| Breadcrumb: Главная > Название филиала                      |
+------------------------------------------------------------+
| KPI-карточки (5 шт.):                                      |
| [Обращ./мес] [Ср.ожидание] [Окон] [Сотрудников] [Пик.час] |
+------------------------------------------------------------+
| Line Chart: Прогноз обращений по дням                       |
| (confidence interval -- полупрозрачная область)             |
+------------------------------------------------------------+
| Heatmap: Загрузка "День недели x Час"                       |
| 7 строк (Пн-Вс) x 12 столбцов (08:00-19:00)              |
+------------------------------------------------------------+
| Табы: [Прогноз] [Окна] [Штат] [История]                    |
+------------------------------------------------------------+
```

**KPI-карточки:**

| # | Карточка | Формат |
|---|----------|--------|
| 1 | Обращений в месяц (прогноз) | `3 200` |
| 2 | Среднее ожидание | `12,3 мин` |
| 3 | Кол-во окон | `8` |
| 4 | Кол-во сотрудников | `12` |
| 5 | Пиковый час | `Вт, 11:00` (день + час) |

**Line Chart (Прогноз обращений по дням):**

- **X-axis:** дни месяца (1--31). Формат меток: `1`, `2`, ... или `01.03`, `02.03`, ...
- **Y-axis:** суммарные обращения за день. Метка: «Обращений».
- **Основная линия:** `predicted_visits` (сумма по часам за день). Цвет: `#2563EB` (синий). Толщина: 2px.
- **Confidence interval:** полупрозрачная область между `confidence_lower` и `confidence_upper`. Цвет: `#2563EB` с opacity 0.15.
- **Tooltip при hover:** дата, прогноз (число), интервал (нижняя--верхняя граница).
- **Zoom:** возможность увеличения участка по оси X (drag-select).
- **Выходные дни:** отмечены вертикальной серой полосой или уменьшенной opacity.

**Heatmap (Загрузка "День недели x Час"):**

- **Строки (7 шт.):** Пн, Вт, Ср, Чт, Пт, Сб, Вс. Метки слева.
- **Столбцы (12 шт.):** 08:00, 09:00, 10:00, ..., 19:00. Метки сверху.
- **Значение ячейки:** среднее прогнозное количество обращений за этот час в этот день недели (за весь месяц).
- **Цвет ячейки:** по градиенту (см. раздел 3.3).
- **Tooltip при hover:** день недели (текст), час, среднее количество обращений, среднее ожидание.
- **Число в ячейке:** отображается, если ячейка достаточно крупная (ширина >= 48px).

### 4.3. Windows (Окна) -- `/branch/:id/windows`

**Назначение:** Детализация загрузки по каждому окну филиала. Позволяет менеджеру увидеть перегруженные и простаивающие окна.

**Структура:**

```
+------------------------------------------------------------+
| Breadcrumb: Главная > Название филиала > Окна               |
| Фильтр: [Выбрать день: все дни v]                          |
+------------------------------------------------------------+
| Таблица окон:                                               |
| [Окно] [Обращ./день] [Ср.загрузка %] [Ср.ожидание] [Стат.]|
+------------------------------------------------------------+
| Детализация по часам (если выбран конкретный день):          |
| [Окно] [08] [09] [10] ... [19]                             |
+------------------------------------------------------------+
| Легенда цветов                                              |
+------------------------------------------------------------+
```

**Таблица окон:**

| Столбец | Описание | Формат |
|---------|----------|--------|
| Окно | Номер окна | `Окно 1`, `Окно 2`, ... |
| Ср. обращений/день | Среднее кол-во обращений за рабочий день | `28,5` |
| Ср. загрузка (%) | Средний процент загрузки | `78,5%` с цветовым индикатором |
| Ср. ожидание | Среднее время ожидания в минутах | `12,3 мин` |
| Статус | Цветной бейдж | `Перегружено` / `Норма` / `Низкая` / `Простой` |

- **Цветовой индикатор:** в каждой строке -- цветная полоса или бейдж в соответствии с уровнем загрузки (раздел 3.1).
- **Сортировка:** по умолчанию -- по загрузке (перегруженные сверху). Кликабельные заголовки.
- **Фильтр по дню:** выпадающий список дат месяца. По умолчанию: «Все дни» (среднее). При выборе конкретного дня -- показать почасовую детализацию.

**Почасовая детализация (при выборе дня):**

- Таблица: строки = окна, столбцы = часы (08--19).
- Значение ячейки: количество обращений или процент загрузки.
- Цвет ячейки: по шкале загрузки (раздел 3.1).

**Пустое состояние:** «Нет данных по окнам для этого филиала.»

### 4.4. Staffing (Штат) -- `/branch/:id/staffing`

**Назначение:** Рекомендации по количеству сотрудников/окон для каждого часа каждого рабочего дня месяца.

**Структура:**

```
+------------------------------------------------------------+
| Breadcrumb: Главная > Название филиала > Штат               |
+------------------------------------------------------------+
| Summary-блок:                                               |
| Рекомендуемое ср. кол-во окон: 5 (текущее: 3)             |
| Дней с дефицитом: 12 из 22                                 |
+------------------------------------------------------------+
| Матрица: Дни x Часы                                        |
| [Дата]  [08] [09] [10] [11] ... [19] [Макс за день]       |
| 02.03    2    3    5    6  ...   2       6                  |
| 03.03    3    4    5    5  ...   2       5                  |
+------------------------------------------------------------+
| Легенда:                                                    |
| [Красный: дефицит >=2] [Желтый: дефицит 1] [Зеленый: ОК]  |
+------------------------------------------------------------+
```

**Матрица штата:**

- **Строки:** рабочие дни месяца. Формат: `02.03 Пн`, `03.03 Вт`, ...
- **Столбцы:** рабочие часы 08:00--19:00 (12 столбцов) + итоговый столбец «Макс за день».
- **Значение ячейки:** рекомендуемое количество сотрудников (окон) в этот час.
- **Цвет ячейки:**
  - Красный (`#EF4444`): дефицит >= 2 (`delta >= 2`, т.е. `required - current >= 2`).
  - Желтый/Оранжевый (`#F97316`): дефицит 1 (`delta == 1`).
  - Зеленый (`#22C55E`): норма или избыток (`delta <= 0`).
  - Серый (`#9CA3AF`): избыток >= 2 (`delta <= -2`).

**Summary-блок:**

- Среднее рекомендуемое кол-во окон vs текущее среднее.
- Количество дней/часов с дефицитом.
- Если дефицит критический (>50% часов) -- предупреждение красным.

### 4.5. Compare (Сравнение) -- `/compare`

**Назначение:** Сравнение нескольких филиалов по ключевым метрикам для принятия решений о перераспределении ресурсов.

**Структура:**

```
+------------------------------------------------------------+
| Мультиселект филиалов (до 5)                                |
| [Филиал 1 x] [Филиал 2 x] [+ Добавить филиал v]          |
+------------------------------------------------------------+
| Bar Chart: Сравнение по прогнозу обращений                  |
| (горизонтальные бары, сортировка по убыванию)              |
+------------------------------------------------------------+
| Таблица сравнения:                                          |
| [Филиал] [Обращ.] [Ожидание] [Обсл.] [Пик.час] [Окна]    |
+------------------------------------------------------------+
```

**Мультиселект:**

- Выпадающий список с поиском.
- Минимум 2, максимум 5 филиалов.
- Выбранные филиалы отображаются как теги с кнопкой удаления (x).
- Если выбрано < 2: кнопка «Сравнить» неактивна, подсказка «Выберите минимум 2 филиала».

**Bar Chart:**

- Горизонтальные бары (для длинных названий филиалов).
- Метрика по умолчанию: прогноз обращений. Переключатель метрики: обращения / ожидание / загрузка.
- Сортировка: по убыванию значения.
- Каждый бар окрашен в цвет по шкале загрузки.
- Tooltip: название филиала, точное значение.

**Таблица рэнкинга:**

| Столбец | Формат |
|---------|--------|
| Филиал | Название |
| Прогноз обращений | `3 200` |
| Ср. ожидание (мин) | `12,3` |
| Ср. обслуживание (мин) | `15,1` |
| Пиковый час | `11:00` |
| Рекомендуемые окна (ср.) | `5` |
| Перегруженных часов | `8` |

- Строки отсортированы по выбранной метрике.
- Первое место выделено жирным шрифтом.
- Цветовые индикаторы в столбцах загрузки и ожидания.

### 4.6. History (История) -- `/history/:id`

**Назначение:** Отображение исторических данных и сравнение факта с прогнозом для оценки качества модели.

**Структура:**

```
+------------------------------------------------------------+
| Breadcrumb: Главная > Название филиала > История            |
| Выбор периода: [2023-01] -- [2024-02]                      |
+------------------------------------------------------------+
| Line Chart: Факт (синий) vs Прогноз (оранжевый, пунктир)  |
| (дневная агрегация)                                        |
+------------------------------------------------------------+
| Метрики качества:                                           |
| MAPE = 15,3%  |  MAE ожидания = 3,8 мин  |  CI покрытие = 81% |
+------------------------------------------------------------+
| Heatmap: Фактическая загрузка "День недели x Час"           |
+------------------------------------------------------------+
```

**Line Chart (Факт vs Прогноз):**

- **Линия факта:** сплошная, синяя (`#2563EB`), толщина 2px.
- **Линия прогноза:** пунктирная, оранжевая (`#F97316`), толщина 2px.
- **Tooltip:** дата, факт, прогноз, отклонение (абс. и %).
- **Zoom:** drag-select по оси X.

**Метрики качества:**

- Отображаются в строку, каждая в отдельной карточке.
- Цвет значения: зеленый если в пределах целевого, красный если нет (MAPE: < 20% = зеленый, >= 20% = красный).

## 5. Адаптивность

### 5.1. Поддерживаемые разрешения

| Тип | Минимум | Оптимум |
|-----|---------|---------|
| Десктоп | 1280 x 720px | 1920 x 1080px |
| Планшет (горизонтально) | Не в MVP | -- |
| Мобильный | **Не в MVP** | -- |

### 5.2. Поведение на минимальной ширине (1280px)

- Sidebar: 280px. Возможность сворачивания до 64px (иконки).
- Content area: минимум 1000px при развернутом sidebar, 1216px при свернутом.
- Таблицы: горизонтальный скролл при нехватке ширины (для таблиц с множеством столбцов, например, почасовой матрицы штата).
- KPI-карточки: в одну строку (4--5 шт.).
- Графики: масштабируются по ширине контейнера. Минимальная высота: 300px для line chart, 250px для heatmap.

### 5.3. Breakpoints

| Breakpoint | Ширина | Изменение |
|------------|--------|-----------|
| `lg` | >= 1280px | Основной layout (sidebar + content) |
| `xl` | >= 1536px | Более просторные отступы, более крупные графики |

## 6. Критерии UX-приемки

### 6.1. Производительность

| Критерий | Целевое значение |
|----------|------------------|
| Время до первого полезного экрана (FCP) | < 3 секунды |
| Время загрузки данных API | < 2 секунды (с loading spinner) |
| Отклик UI на действие пользователя | < 200 мс |

### 6.2. Навигация и доступность данных

| Критерий | Целевое значение |
|----------|------------------|
| Любой прогноз доступен от главной страницы | <= 2 клика |
| Переход между филиалами | 1 клик (sidebar) |
| Смена периода прогноза | 1 клик (MonthPicker) |

### 6.3. Единообразие

| Критерий | Описание |
|----------|----------|
| Цветовая кодировка загрузки | Одинакова на всех страницах (шкала из раздела 3.1) |
| Формат чисел | Разделители тысяч (пробел): `126 000`. Проценты: 1 знак после запятой (`78,5%`). Время: 1 знак (`12,3 мин`). |
| Locale | Русская: запятая как десятичный разделитель, пробел как разделитель тысяч |

### 6.4. Интерактивность

| Критерий | Описание |
|----------|----------|
| Heatmap | Tooltip при hover с точным значением |
| Line Chart | Tooltip при hover + zoom/pan |
| Bar Chart | Tooltip при hover |
| Таблицы | Сортировка по клику на заголовок столбца |
| Индикаторы загрузки | Spinner при загрузке данных, минимальное время отображения 300 мс (чтобы не мигал) |

### 6.5. Обработка пустых и ошибочных состояний

| Состояние | Поведение |
|-----------|-----------|
| Нет данных прогноза | Сообщение: «Нет данных прогноза на выбранный месяц.» + кнопка/инструкция |
| Нет данных по филиалу | Сообщение: «Данные для этого филиала отсутствуют.» |
| Ошибка API (500) | Сообщение: «Не удалось загрузить данные. Попробуйте позже.» + кнопка «Повторить» |
| Филиал не найден (404) | Сообщение: «Филиал не найден.» + ссылка на главную |
| Загрузка данных | Skeleton-loader или spinner в зоне контента (не блокирует навигацию) |
| Пустая таблица | Строка: «Нет данных для отображения.» (не пустая таблица без строк) |
| Пустой график | Placeholder: «Недостаточно данных для построения графика.» |

### 6.6. Форматирование данных

| Тип данных | Формат | Пример |
|------------|--------|--------|
| Целые числа (обращения) | Разделитель тысяч (пробел) | `126 000` |
| Проценты | 1 десятичный знак, запятая | `78,5%` |
| Время (минуты) | 1 десятичный знак + «мин» | `12,3 мин` |
| Даты | `DD.MM.YYYY` | `02.03.2026` |
| Месяц (MonthPicker) | Название + год | `Март 2026` |
| Дни в матрице штата | `DD.MM Дн` | `02.03 Пн` |
| Часы | `HH:00` | `09:00` |
